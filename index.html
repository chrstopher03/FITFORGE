Mis carreras

Escanear comida

Escanea el código de barras de un producto para consultar sus datos nutricionales reales. Para comida sin código, la app permite una estimación manual; una foto por sí sola no puede garantizar calorías exactas.

Escaneo por foto

Toma una foto y la IA puede identificar alimentos y dar una estimación de calorías por porción.

La foto no puede medir gramos exactos; la estimación debe verificarse con una etiqueta o una balanza cuando sea importante.

Apunta al código de barras para consultar producto, calorías, proteína, carbohidratos y grasas.

Importante: los datos de Open Food Facts provienen de una base abierta alimentada por usuarios y pueden estar incompletos o contener errores. FITFORGE mostrará la fuente y no inventará valores cuando no estén disponibles.

Dolores y bienestar

Orientación general para molestias comunes. FITFORGE no diagnostica enfermedades y no sustituye a un profesional de salud.

Evaluación de bienestar

Basada en datos que tú registras, no en tu cara.

Señales para detener el ejercicio

Dolor intenso o creciente, dificultad para respirar, desmayo, confusión, debilidad súbita o síntomas graves requieren atención médica urgente.

Consejo de seguridad

Si el dolor es nuevo, intenso, persistente o empeora, consulta a un profesional. No uses la app para decidir si una lesión es segura de entrenar.
