FITFORGE — app web responsive
1. Abre index.html para probarla.
2. Los datos de perfil, entrenamientos e historial se guardan en localStorage.
3. Para instalarla como PWA desde HTTPS, registra sw.js y enlaza el manifest.
4. Las fotos usan URLs de Unsplash y el avatar usa pravatar.cc; para una app comercial conviene alojar tus propios recursos.
5. Esta versión es funcional en frontend. Para cuentas reales, sincronización entre dispositivos, pagos, notificaciones push y almacenamiento en servidor hace falta conectar un backend/API.
